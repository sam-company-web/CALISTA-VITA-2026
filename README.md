# CALISTA VITA — Static Brand Website

Static, single-page website. The main entry point is `index.html`.

## Deploy to GitHub + Vercel
1. Upload the contents of this folder to a GitHub repository.
2. Import the repository into Vercel.
3. No database, admin, payment system, or backend is required.
4. Vercel can serve the static site directly.
